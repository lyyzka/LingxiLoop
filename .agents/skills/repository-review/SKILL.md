# Repository review

Stay read-only and freeze the requested scope. Trace changed call sites, data flows, deployments, and public-boundary tests.

Prioritize correctness, data loss, authorization, tenant isolation, migrations, retry/idempotency, contracts, and missing behavior coverage. Every finding needs severity, exact location, failing scenario, and smallest correction. Lead with findings; otherwise state residual risk and unverified gates.
